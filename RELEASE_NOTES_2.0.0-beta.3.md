# FOUNDRY 2.0.0-beta.3

This is an **ACAS Tools private-beta prerelease**, provided for approved testers.
It is not the final production release.

## Included

- Local-first product intake, research, strategy, and channel-content workflow
- Safe Preview and configurable hosted/local AI providers
- Obsidian-compatible Markdown workspaces
- Product assets, approvals, and execution modes
- Supervised, resumable channel handoffs with audit history
- Gumroad, Patreon, Product Hunt, KVR, social, and custom-channel preparation
- Responsive desktop interface and system tray
- Authenticated update manifests and verified package staging

## Current platform

- macOS Apple Silicon beta

Windows is awaiting a native build after the GitHub Actions account billing gate
is resolved. Linux is not part of the first supported cohort.

## Important

This beta is not Developer ID signed or notarized. Use it only when received from
ACAS Tools and verify the published SHA-256 digest. FOUNDRY does not enter website
credentials or independently publish external actions.
