# FOUNDRY 2.0.0-beta.16

Beta.16 is the broader private-beta candidate for FOUNDRY's local-first product
launch workspace.

## Highlights

- Dedicated supervised Chrome Companion preparation for Gumroad, Patreon, and
  Product Hunt.
- Frozen adapter and companion contract version 1 for stable future expansion.
- Clear, actionable explanation when incomplete draft fields or missing assets
  prevent a browser run and pairing code.
- Cross-platform database cleanup and run-ID hardening.
- Isolated Windows DLL resolution in the native packaging path.
- Responsive interface scaling, Live AI and Safe Preview pipelines, Obsidian
  output, Telegram control, bulk approvals, resumable handoffs, and privacy-safe
  diagnostics.

## Updating

Use **Check for Updates** in FOUNDRY's status bar, overflow menu, or system-tray
menu. FOUNDRY authenticates the release manifest and verifies the installer
digest before staging it. Installation remains a visible user-confirmed operating
system step; FOUNDRY never silently executes a downloaded installer.

## Private-beta trust status

The Mac package uses an ad-hoc beta signature and is not yet Developer ID signed
or notarized. The Windows installer is not yet Authenticode signed. Only install
artifacts distributed through the authenticated ACAS Tools update channel.
